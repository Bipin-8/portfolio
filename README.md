# Bipin Pokhrel - Portfolio Website

A modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Responsive Design** - Works seamlessly on all devices
- **Theme Switcher** - Choose from multiple color themes (Light, Dark, Ocean, Purple, Forest)
- **Smooth Animations** - Engaging user experience with smooth transitions
- **Professional Sections**:
  - Home - Eye-catching hero section
  - About - Personal introduction
  - Skills - Technical expertise with progress bars
  - Projects - Showcase of work
  - Contact - Get in touch form

## 🛠️ Technologies Used

- **React** - UI library
- **TypeScript** - Type-safe JavaScript
- **Tailwind CSS** - Utility-first CSS framework
- **React Context API** - State management for themes

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/Bipin-8/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 🎨 Theme Customization

The portfolio includes 5 built-in themes:
- ☀️ Light - Clean and professional
- 🌙 Dark - Easy on the eyes
- 🌊 Ocean - Blue tones
- 💜 Purple - Creative and bold
- 🌲 Forest - Green and natural

Users can switch themes using the theme icon in the navigation bar.
